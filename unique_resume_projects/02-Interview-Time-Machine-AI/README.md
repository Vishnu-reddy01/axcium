# Interview Time Machine AI
An interview platform that remembers previous interview sessions and deliberately revisits weaknesses.

## Unique idea
The interviewer becomes harder based on your history.

Example:
Session 1 -> weak Java concurrency
Session 2 -> asks concurrency follow-up
Session 5 -> gives a scenario-based concurrency question

## Stack
React, Spring Boot, PostgreSQL, LLM API, RAG/vector database.

## MVP
This starter includes the interview-history model and a prompt engine.
